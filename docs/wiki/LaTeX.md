# Using Schematrix in LaTeX

There are three ways to put a schematic in a LaTeX document. **TikZ** is the best: the figure's text is typeset by
LaTeX in your document's font, lines stay sharp at any zoom, and the file is small plain text that diffs nicely in
version control.

| Way | Text font | Scales with | Needs |
|---|---|---|---|
| **TikZ** (`\input`) | the document's | `\resizebox` | `tikz` |
| **PDF** (`\includegraphics`) | the theme's (embedded in the PDF) | `width=` | `graphicx` |
| **SVG** (`\includesvg`) | the theme's | `width=` | `svg` package + Inkscape + `-shell-escape` |

![A TikZ export compiled with pdflatex](img/latex-tikz.png)

## 1. Prepare the drawing

- Use the **`formal`** theme (document inspector > Theme, or `Schematic(theme='formal')`): black, thin even lines,
  italic references and serif text, which matches Computer Modern / Latin Modern / Times documents. `technical` suits
  sans-serif documents.
- Keep **Auto size** on (so the export is cropped to the drawing) and no page frame.
- Write symbols with [markup](Text-Markup.md): `R_{1}`, `10 k\ohm`, `~{CS}`, `V_{OUT}`; TikZ turns them into
  `R\textsubscript{1}`, `10 k$\Omega$`, `\overline{CS}`.
- For equations, write LaTeX maths in the label itself: `$A_v = -\frac{R_f}{R_{in}}$`. TikZ passes it to LaTeX
  unchanged, so it is typeset by your document with its maths fonts ([details](Text-Markup.md#latex-maths)).
- The `formal` and `technical` themes draw with TeX Gyre Termes / Heros (free Times / Helvetica clones that ship
  with Schematrix), so PDF and SVG exports look the same on every computer.

## 2. Export TikZ

Export dialog (`Ctrl E`) > **TikZ**, or *Export > TikZ (LaTeX)*, or:

```bash
schematrix render figure.json -o figures/amplifier.tikz
schematrix render figures.py -o figures/ -f tikz          # every figure a script makes
```

The file is a single `tikzpicture` with its colours defined inside it:

```latex
% Differential amplifier: generated by Schematrix. Needs \usepackage{tikz}.
\begin{tikzpicture}[x=0.75pt, y=-0.75pt, line join=round]
  \definecolor{sx1}{HTML}{000000}
  \path[draw=sx1, line width=0.75pt, line join=miter, line cap=butt] (100,115) -- (130,115) ...;
  \node[anchor=base, inner sep=0, font=\fontsize{9}{10.8}\selectfont\itshape, text=sx1] at (190,103) {R\textsubscript{1}};
  ...
\end{tikzpicture}
```

## 3. Use it

```latex
\documentclass[11pt]{article}
\usepackage[T1]{fontenc}
\usepackage{lmodern}
\usepackage{tikz}         % for the Schematrix figures
\usepackage{graphicx}     % \resizebox (and PDF figures)

\begin{document}
\begin{figure}[ht]
  \centering
  \input{figures/amplifier.tikz}
  \caption{Difference amplifier.}
  \label{fig:amp}
\end{figure}
\end{document}
```

Compile with `pdflatex`, `xelatex` or `lualatex` as usual. On **Overleaf**, upload the `.tikz` files to a `figures/`
folder and `\input` them the same way.

### Size

The figure comes out at the drawing's natural size: 1 drawing unit = 0.75 pt, text at 7.9–9 pt, lines 0.5–1.3 pt
(with `formal`). To fit a width, scale it (text and lines scale too):

```latex
\resizebox{\linewidth}{!}{\input{figures/sallen-key.tikz}}      % full text width
\resizebox{0.6\linewidth}{!}{\input{figures/amplifier.tikz}}    % 60 %
```

To keep the text size constant across figures, avoid scaling and draw the figures at similar sizes instead.

### Side by side

```latex
\usepackage{subcaption}
...
\begin{figure}[ht]
  \centering
  \begin{subfigure}{0.48\linewidth}\centering
    \resizebox{\linewidth}{!}{\input{figures/before.tikz}}\caption{Before}
  \end{subfigure}\hfill
  \begin{subfigure}{0.48\linewidth}\centering
    \resizebox{\linewidth}{!}{\input{figures/after.tikz}}\caption{After}
  \end{subfigure}
  \caption{The two stages.}
\end{figure}
```

### Many figures, one script

Keep every figure of a paper in one Python script and regenerate them all whenever something changes:

```python
# figures.py
from schematrix import Schematic

def amplifier():
    s = Schematic('amplifier', theme='formal')
    ...
    return s

for make in (amplifier, ):
    make().export(f'figures/{make.__name__}.tikz')
```

```bash
python figures.py        # or:  schematrix render figures.py -o figures/ -f tikz
```

## Standalone figures

*LaTeX standalone (TikZ)* (or `-o fig.tex`) writes a complete document with the `standalone` class that compiles to
a PDF cropped to the figure:

```bash
schematrix render fig.json -o fig.tex && pdflatex fig.tex      # -> fig.pdf
```

Useful for Beamer slides, journals that want separate figure files, or checking a figure on its own.

## PDF instead of TikZ

```latex
\includegraphics[width=0.8\linewidth]{figures/amplifier.pdf}
```

Export *PDF*. The text keeps the theme's font, drawn as outlines from the bundled fonts (see
[Exporting](Exporting.md#how-exports-are-made)). Fine when the figure's font need not match the document, or for
editors that don't take TikZ.

## SVG directly

With the `svg` package and Inkscape installed, compile with `-shell-escape`:

```latex
\usepackage{svg}
...
\includesvg[width=0.8\linewidth]{figures/amplifier}
```

## What TikZ export supports

Everything the editor draws: symbols, wires (including hops and bus wires), junction dots, net labels, texts, boxes,
arrows, raw SVG from legacy figures, page frames, every theme's colours and line weights, markup (overbars,
sub/superscripts, Greek letters, Ω, µ, °, ±, ≤, ≥, …). Characters LaTeX treats specially (`# $ % & _ { } ~ ^ \`) are
escaped.

## Tips

- **Hyphen vs minus**: write `\-` for a true minus (`\-12 V`); TikZ gets `$-$`.
- **Units**: put a space between number and unit (`10 k\ohm`), as in the SI style; `siunitx` is not needed.
- **Colour**: `print-mono` and `formal` are pure black; `instrix` uses its brand blue-greys.
- **Version control**: commit the script or the `.json` and regenerate the `.tikz` files; or commit the `.tikz` files
  too, they diff line by line.
