# Keyboard and mouse

Press `?` in the editor for this list, `F1` for the [text markup](Text-Markup.md) reference.

## Tools

| Key | |
|---|---|
| `V` | Select |
| `W` | Wire |
| `L` | Net label |
| `T` | Text |
| `B` | Group box |
| `A` | Arrow |
| `/` | Find a symbol (while drawing a wire: flip the elbow) |
| `Esc` | Cancel / finish / back to Select / clear the selection |

## Editing

| Key | |
|---|---|
| `R` | Rotate 90° (also while placing) |
| `M` | Mirror (also while placing) |
| `E` | Toggle accent style |
| `Del` / `Backspace` | Delete (while drawing a wire: remove the last corner) |
| Arrow keys | Nudge one grid step; with `Shift`, four |
| `Ctrl Z` / `Ctrl Y` (`Ctrl Shift Z`) | Undo / redo |
| `Ctrl X` / `Ctrl C` / `Ctrl V` | Cut / copy / paste (through the system clipboard, so across tabs and windows) |
| `Ctrl D` | Duplicate |
| `Ctrl A` | Select all |
| `Ctrl F` | Find and replace |
| `Ctrl ]` / `Ctrl [` | Bring to front / send to back |
| `PgUp` / `PgDn` | Bring forward / send backward |
| `Enter` | Finish a wire or arrow |

## Files and views

| Key | |
|---|---|
| `Ctrl N` | New schematic |
| `Ctrl O` | Open from the workspace |
| `Ctrl S` / `Ctrl Shift S` | Save / save as |
| `Ctrl E` | Export… |
| `Ctrl Enter` | Run the script (Script pane) |
| `F` | Fit |
| `+` `=` / `-` | Zoom in / out |
| `1` | Actual size |
| `G` | Grid on / off |
| `F1` | Text markup reference |
| `?` | Keyboard shortcuts |

## Mouse

| Action | |
|---|---|
| Click | Select (`Shift` / `Ctrl`-click adds or removes) |
| Drag a part, text or box | Move it (attached wires stretch) |
| Drag a wire end | Stretch the wire |
| Drag the middle of a wire segment | Slide the segment |
| `Alt`-drag a wire | Move the whole wire |
| Drag on empty space | Box-select (left→right: inside; right→left: touching) |
| Double-click a text | Edit it in place |
| Double-click a wire segment | Add a corner |
| Right-click | Context menu |
| Right drag, middle drag, `Space`-drag | Pan |
| Wheel / two-finger scroll | Zoom / pan |
| Drag a palette tile onto the sheet | Place one part |
| Right-click a palette tile | Customise / edit the symbol |

## Symbol editor

| Key | |
|---|---|
| `V` `L` `G` `R` `C` `T` `P` | Select, line, shape, rectangle, circle, text, pin |
| `Enter` / double-click | Finish a line or shape |
| `Del` | Delete the selection (while drawing: the last point) |
| Arrow keys | Nudge (`Shift`: ×4) |
| `Ctrl D` | Duplicate the shape |
| `Ctrl Z` / `Ctrl Y` | Undo / redo |
| `Ctrl S` | Save to the library |
| `F` | Fit |
| Right drag / wheel | Pan / zoom |
